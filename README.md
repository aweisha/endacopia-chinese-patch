# endacopia-chinese-patch
一款使用deepseek Ai专门为游戏Endacopia制作的非官方中文补丁包
==================================
  Endacopia 简体中文汉化补丁 v1.0
==================================

适配版本: Endacopia (AGS 3.6.0.55)
翻译覆盖率: 98.9% (7937/8025)
字体: 混合字体 (Silkscreen 英文 + LanaPixel 中文)

==================================
  安装方法
==================================

将补丁内两个文件复制到游戏目录下的 Data 文件夹:

  Endacopia_CN.tra  →  <游戏目录>/Data/
  agsfnt0.ttf       →  <游戏目录>/Data/

然后在游戏目录下找到 acsetup.cfg，在 [language] 段落下添加:

  [language]
  translation=Endacopia_CN.tra

如已存在 translation= 行，替换为上面这行即可。

==================================
  文件说明
==================================

Endacopia_CN.tra - 中文翻译文件 (7937 条)
agsfnt0.ttf      - 中文字体外挂 (Silkscreen + LanaPixel)
